# Tech Fusion — সাইট চালানোর গাইড

## নতুন প্রোডাক্ট যোগ করবেন যেভাবে (কোনো কোডিং লাগবে না)

### ধাপ ১ — ছবি আপলোড করুন
1. আপনার GitHub রিপোজিটরির `images` ফোল্ডারে যান।
2. **Add file → Upload files** চাপুন।
3. আপনার ল্যাপটপ/মোবাইল থেকে প্রোডাক্টের ছবি (jpg/png) টেনে ছাড়ুন বা সিলেক্ট করুন।
4. নিচে **Commit changes** চাপুন।

> ছবির নাম সহজ রাখুন, স্পেস ছাড়া — যেমন `fusion-buds-air.jpg`

### ধাপ ২ — `products.json` ফাইলটা এডিট করুন
1. রিপোজিটরির root-এ `products.json` ফাইলে ক্লিক করুন।
2. ডান পাশে পেন্সিল আইকনে (Edit) ক্লিক করুন।
3. লিস্টের শেষে একটা নতুন প্রোডাক্ট ব্লক যোগ করুন, এই প্যাটার্নটা কপি করে বসান:

```json
,
  {
    "tag": "ক্যাটাগরির নাম",
    "name": "প্রোডাক্টের নাম",
    "price": "৳ ৫,০০০",
    "description": "এক লাইনে সংক্ষিপ্ত বর্ণনা",
    "image": "images/আপনার-ছবির-নাম.jpg",
    "shape": ""
  }
```

4. এটা বসাতে হবে ঠিক শেষ `}` এর পরে, `]` এর আগে (উদাহরণ নিচে দেখুন)।
5. নিচে **Commit changes** চাপলেই সাইট নিজে থেকে আপডেট হয়ে যাবে (১-২ মিনিট সময় লাগতে পারে)।

#### উদাহরণ — শেষে একটা নতুন প্রোডাক্ট যোগ করার পর ফাইলটা কেমন দেখাবে:
```json
[
  { "tag": "...", "name": "...", "price": "...", "description": "...", "image": "...", "shape": "phone" },
  { "tag": "...", "name": "...", "price": "...", "description": "...", "image": "...", "shape": "earbud" },
  { "tag": "...", "name": "...", "price": "...", "description": "...", "image": "...", "shape": "watch" },
  {
    "tag": "ল্যাপটপ",
    "name": "Fusion Book 14",
    "price": "৳ ৫৮,০০০",
    "description": "Core i5, 16GB RAM, 512GB SSD",
    "image": "images/fusion-book-14.jpg",
    "shape": ""
  }
]
```

⚠️ **সবচেয়ে সাধারণ ভুল:** প্রতিটা `{...}` ব্লকের পর কমা `,` বসাতে ভুলবেন না (একদম শেষ ব্লকের পর কমা লাগবে না)। কমা ভুল হলে সাইটে প্রোডাক্ট দেখাবে না।

### ধাপ ৩ — মোবাইল থেকেও করা যাবে
GitHub-এর মোবাইল ওয়েবসাইট বা GitHub অ্যাপ দিয়েও উপরের একই কাজ করা যায় — Upload files আর Edit বাটন দুটোই মোবাইলে কাজ করে।

---

## সাইট লাইভ করবেন যেভাবে (GitHub Pages)
1. এই পুরো ফোল্ডারটা (`index.html`, `products.json`, `images/`) আপনার GitHub রিপোতে আপলোড করুন।
2. রিপোর **Settings → Pages** এ যান।
3. Source-এ `main` ব্রাঞ্চ সিলেক্ট করে Save চাপুন।
4. ১-২ মিনিট পর একটা লিংক পাবেন যেমন `https://yourusername.github.io/repo-name/` — এটাই আপনার লাইভ সাইট।

## ছবি ছাড়া প্রোডাক্ট
`image` ফিল্ড খালি (`""`) রাখলে সাইট একটা ডিফল্ট আইকন দেখাবে — ছবি রেডি না থাকলে চিন্তা নেই, পরে যোগ করলেই চলবে।
